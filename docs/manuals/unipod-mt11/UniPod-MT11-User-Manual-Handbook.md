## 1. 产品速览

迷你四光 AI 吊舱：广角 + 变焦 + 热成像 + 激光测距；内置 **10 TOPS** AI；约 **405 g**（不含快拆爪）；IP54；极限空速约 **140 km/h**。

| 项 | 值 |
|----|----|
| 含爪重量 | 533.5 g ±5（含拓展坞） |
| 供电 | **10–26 V**（3–6S）独立供电，≥5 A |
| 控制 | S.BUS / UART / 以太网 TCP·UDP |
| 视频 | 以太网 RTSP（主/副双路） |
| 可控俯仰 | **-90° ~ 20°**（技术参数）；航向 360° 无限 |
| 光学变焦 | 11×；混合变焦 165× |
| 激光 | 905 nm，**5–1200 m**，±1 m |

完整规格表见数据库 `specs`。

## 2. 常用网络地址（出图）

| 用途 | 地址 |
|------|------|
| 默认主 IP | `192.168.144.25` |
| 主码流 | `rtsp://192.168.144.25:8554/video1` |
| 副码流 | `rtsp://192.168.144.25:8554/video2` |
| 副 IP | `192.168.144.80` |
| 副 IP 主码流 | `rtsp://192.168.144.80:8554/video1`（改 IP 后需重启才可用） |
| SDK | `192.168.144.25:37260` |

可见光变倍切换（FAQ）：**1.0–3.2 = 广角**，**3.3–11 = 变焦**。广角与变焦**不能分开拉流**。

忘记自改 IP：同一网段用 UniGCS 扫描复位；跨网段可先拉副 IP RTSP，再复位。

## 3. 接口与供电

拓展坞关键口（手册示意）：

1. **UART** — 接飞控 TELEM（TX↔RX），融合姿态 / MAVLink / 私有协议控制  
2. **以太网** — 出图与 SDK  
3. **S.BUS 输入** — 天空端 S.BUS；可一分二同时控飞控  
4. **供电** — MX1.25 4P → XT30，独立供电  

安全要点（节选）：

- 禁止用 ZT30/ZR30 减震爪装 MT11（方向/兼容错误）  
- 禁止红外对太阳等强能量源；勿带电拔 TF / 拆装  
- 关机后间隔 ≥30 s 再开机  

## 4. 云台 / 相机控制路径

| 方式 | 说明 |
|------|------|
| UniGCS | 触控转动、拍照录像、变焦、模式、IP、AI |
| S.BUS | APP 映射 1–16 通道：拍照/录像/对焦/变倍/拼接、云台轴与回中等 |
| UART + ArduPilot MAVLink2 | 飞控 ≥4.4.4；见下表 |
| UART + 私有(SIYI)协议 | 飞控 ≥**4.6.0**（否则无位置/激光经纬度） |
| 外部 SDK | 见 [SDK 手册](UniPod-MT11-SDK-Handbook.md) |

### 4.1 ArduPilot 参数（TELEM1 示例）

**MAVLink2 路径**

| 参数 | 值 | 含义 |
|------|----|------|
| SERIAL1_BAUD | 115 | 115200 |
| SERIAL1_PROTOCOL | 2 | MAVLink2 |
| CAM1_TYPE | 6 | MAVLinkCamV2 |
| MNT1_TYPE | 4 | SToRM32 MAVLink |
| MNT1_RC_RATE | 90 | |
| MNT1_PITCH_MAX / MIN | 20 / -90 | |
| MNT1_YAW_MAX / MIN | 180 / -180 | |

**私有协议路径**

| 参数 | 值 | 含义 |
|------|----|------|
| SERIAL1_BAUD | 115 | 115200 |
| SERIAL1_PROTOCOL | 8 | Gimbal |
| CAM1_TYPE | 4 | Mount(Siyi/…) |
| MNT1_TYPE | 8 | SIYI |
| MNT1_* | 同上 | 俯仰/航向限位 |

写入后断电重启飞控。数据库表：`ardupilot_params`。

## 5. V2.0 特色功能提要

- **AI 识别/跟踪/框选**；自定义模型需 **UniAI Studio**  
- **AI 跟飞**、**双击对准**、海外车牌识别、AI 识别推送（V2.0 新增说明）  
- EIS、ISP、电子去雾、夜视  
- 机头安装模式：不支持锁定模式与 AI 跟踪  
- 热成像：点/区域/全局测温、伪彩、增益、AI 超分、原始温度公式（详见原 PDF 第 7 章）  

拍照文件名后缀习惯：`Z` 变焦、`I` 热成像、`C` 双拼。开启 **8K 拍照** 时光学变倍拍照上限 **11×**。

## 8. 与 QGC 的关系

| 项 | 说明 |
|----|------|
| 主码流 | QGC `UniPod MT11` → `rtsp://192.168.144.25:8554/video1` |
