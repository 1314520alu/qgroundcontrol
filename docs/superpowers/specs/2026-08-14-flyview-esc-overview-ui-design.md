# 飞行页 · 电调状态概览 UI

**日期：** 2026-08-14  
**状态：** 实现中  
**范围：** 重做飞行页工具栏指示器抽屉 `EscIndicatorPage`（不是飞控配置页）  
**方案：** 固定**更宽**浮层 + 按电调路数自适应布局（选项 C + 实现路径 1）  
**主目标设备：** 横屏遥控器（云卓 G20 / 思翼 MK32·UniRC 10 Pro）；高度偏紧是主要约束  
**视觉预览：** [`assets/flyview-esc-overview-preview-12esc-dense-unirc10-pro.png`](assets/flyview-esc-overview-preview-12esc-dense-unirc10-pro.png) — 飞行页宽浮层 · 12 路密表（9–16 档示意）  

## 问题

飞行页点工具栏 ESC 图标会打开 `EscIndicatorPage`：每个电机一张很高的 `SettingsGroupLayout` 卡片。12 路时只能上下滑；界面仍有英文；对比过强、字偏细，叠在深色地图上不舒服。

## 目标

1. 点开后**尽量一次看清全部电调**（默认**不要纵向滚动**；极矮屏才允许只滚主体区）。
2. 始终使用**更宽**浮层（不再用窄抽屉竖堆大卡片）。
3. 按路数分档：**1–4 卡片** / **5–8 紧凑表** / **9–16 密表**。
4. 界面中文；字号略小于配置页「电调遥测」。
5. 错误/故障用**颜色提示**（红字 + 浅红底；卡片绿/红边）。
6. 斑马纹用浅半透明，避免一黑一白刺眼。

## 非目标

- 不改配置页 `APMESCTelemetryComponent`（视觉可对齐；**本轮不抽共享 QML**）。
- 不做电调配置/校准/电机测试/写参数。
- 不新增 MAVLink 解析或 Fact 存储（继续用 `activeVehicle.escs`）。
- 不做历史曲线或导出。

## 入口与浮层框架

| 项 | 决定 |
|----|------|
| 入口 | 不变：`EscIndicator.qml` → `mainWindow.showIndicatorDrawer(EscIndicatorPage)` |
| 外壳 | 继续用 `ToolIndicatorPage` + 现有指示器抽屉样式；面板/表格为**半透明**（地图可透出），不要实心不透白板 |
| 宽度 | 内容 `implicitWidth` 约主内容区 **55–70%**，并设上限（约 10″ 横屏上 720–900px 量级）；抽屉本身已按窗口减边距封顶 |
| 高度 | 不超过「窗口 − 工具栏 − 边距」；优先一屏装下 |
| 结构 | （1）标题 （2）一行摘要 （3）自适应主体 |
| 列宽 | 无数据/占位列（如转速多为 0、故障为 —）偏窄；有实质读数的列（如电压、温度）加宽；节约总宽 |

## 数据

绑定现有 `vehicle.escs` Facts（与配置页电调遥测同源：`ESC_TELEMETRY_*` / `ESC_INFO` / `ESC_STATUS`）。

| 界面 | 来源 |
|------|------|
| 编号 | `id`（显示时 +1） |
| 在线 | 在线位图 / 现有健康判断 |
| 转速 / 电压 / 电流 | `rpm` / `voltage` / `current` |
| 温度 | `temperature` — 无效哨兵值显示 `—` |
| 错误 | `errorCount` |
| 故障 | `failureFlags` → 有标志时显示简短中文 |

最多显示 **16** 路。模型为空 → 仅中文空态。

## 按路数布局

`n = min(escs.count, 16)`。字号约默认字号的 **0.85–0.92 倍**。

| `n` | 模式 | 说明 |
|-----|------|------|
| 1–4 | 2×2 卡片网格（不足 4 则少格） | 每卡：编号圆标 + 转速/电压/电流/温度/错误；正常绿边，离线/故障红边；`errorCount > 0` 时错误值红色 |
| 5–8 | 等高行紧凑表 | 列：`#` 转速 电压 电流 温度 错误（故障列：有标志时显示文案，否则 `—`） |
| 9–16 | 等高行密表 | 同列；更小字 + 更矮行；浅斑马纹；尽量铺满剩余高度 |

**滚动规则：** 摘要固定；仅在极矮屏塞不下时，主体可滚。

## 文案（中文）

| 位置 | 文案 |
|------|------|
| 标题 | 电调状态概览 |
| 摘要 | 正常电机 · 错误总数 |
| 卡片标题 | 电机 N；离线 → `电机 N - 离线` |
| 列/字段 | 转速 · 电压 · 电流 · 温度 · 错误 · 故障 |
| 工具栏小字（可选） | `OK`/`ERR` → **正常** / **异常** |
| 空态 | 未收到电调遥测 |

使用 `qsTr(...)`，源文案直接写中文（与本 fork 配置页电调遥测一致）。

## 颜色与对比

- 正常：绿边 / 默认文字  
- 离线或故障标志：红边  
- `errorCount > 0`：错误数字红色 + 行/卡浅红底  
- 斑马纹：浅半透明交替行 — **不要**深灰/纯白硬切  
- 表模式不要给每个电机再套厚边框大卡片  

## 实现涉及文件

| 文件 | 改动 |
|------|------|
| `src/Toolbar/EscIndicatorPage.qml` | 主改：加宽内容 + 三档布局 + 中文 + 颜色 |
| `src/Toolbar/EscIndicator.qml` | 可选：正常/异常；若健康判断仍只看前 4 路则一并修 |
| 抽屉 / `ToolIndicatorPage` | 仅当单靠页面 `implicitWidth` 达不到目标宽度时再动 |

## 验收标准

1. 4 / 8 / 12（及 16）路：在 UniRC 10 Pro 类横屏上点开指示器，卡片或表格**默认无需滚动**即可看全。  
2. 本页用户可见文案均为中文。  
3. 有错误/故障的电调不用逐个数也能看出来。  
4. 不依赖修改配置页「电调遥测」即可交付本功能。
